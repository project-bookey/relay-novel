# relay novel

작은 상상들이 모여 하나의 소설이 되는 릴레이 집필 앱. 크림색 종이, 파스텔 별사탕, 차분한 초록색을 사용합니다. 홈의 별사탕은 Three.js + Expo GL로 직접 렌더링하고, 목록은 가벼운 그라데이션 SVG를 사용합니다.

**Expo / React Native · iOS / Android / Web preview**

## 실행

```sh
npm ci
npm start
# 브라우저 미리보기
npm run web
```

Expo Go 또는 개발 빌드로 앱을 실행합니다. 실제 기기의 3D 렌더링은 별도 검증이 필요합니다. 렌더러 초기화 실패 시 SVG 별사탕으로 대체합니다. 시스템의 동작 줄이기 설정을 따르고, 백그라운드에서는 렌더링을 멈춥니다.

로그인 화면에서 **먼저 둘러보기**를 선택하면 예시 작품을 읽을 수 있습니다. 미리보기의 작품은 샘플이며 서버에 저장되거나 발행되지 않습니다.

## 기존 백엔드 연결

[project-bookey-backend](https://github.com/project-bookey/project-bookey-backend)의 기존 `/api/v1/novels` API를 사용합니다. 별도의 백엔드나 데이터베이스를 만들지 않습니다. 기존 백엔드 저장소는 이 작업에서 변경하지 않았습니다.

```sh
cp .env.example .env.local
```

`.env.local`의 `EXPO_PUBLIC_API_URL`에 기존 백엔드 주소를 입력합니다. 실제 기기에서 로컬 서버를 사용하면 Mac의 LAN IP(예: `http://192.168.0.10:8080`)가 필요합니다. 환경변수가 없으면 개발 서버 호스트에서 로컬 백엔드 주소를 추론합니다. Android 에뮬레이터에서는 필요에 따라 `http://10.0.2.2:8080`을 지정하세요. 배포 시 HTTPS API 주소를 지정하세요. 웹 미리보기에서는 백엔드 CORS에 미리보기 출처가 허용되어 있어야 합니다.

기존 Bookey 이메일 계정으로 로그인하며, 모바일 토큰은 OS의 SecureStore에 저장합니다. 웹 미리보기에서는 토큰을 메모리에만 보관하므로 새로고침 시 로그인이 해제됩니다. 액세스 토큰 만료 시 갱신 요청을 공유하고 요청을 한 번 재시도합니다.

API 타입은 현재 백엔드 `NovelDtos.java` 계약에 맞췄습니다. 백엔드 배포 주소와 테스트 계정은 포함하지 않았으며, 실서버 통합 검증은 별도로 필요합니다.

## 릴레이 흐름

1. 개설자가 공개 또는 초대 코드 방식으로 작품을 만들고 작가를 모집합니다.
2. 참가자가 신청하고 개설자가 승인합니다. 최소 2명의 작가가 모이면 릴레이를 시작합니다.
3. 현재 작가가 앞선 회차를 읽고 다음 회차를 집필합니다. 원고는 서버에 임시저장할 수 있습니다.
4. 발행 확인 후 회차를 등록하면 다음 작가에게 차례가 넘어갑니다. `turnNumber`를 전송해 오래된 차례의 발행을 서버에서 거부합니다.
5. 제한 시간 초과, 회차 제한, 완결 등 차례의 실제 판정은 기존 백엔드가 담당합니다. 앱은 `canWrite`, `canStart`, `canComplete` 등 서버 권한을 따릅니다.

탐색 / 내 차례 / 내 작품, 모집·집필·완결 필터, 불러온 작품 검색, 페이지 추가 로딩, 참가 승인·거절, 초대 코드 공유, 회차 읽기, 수동 임시저장과 발행을 제공합니다. 시간 제한으로 집필 차례가 바뀌어도 열린 편집기의 원고를 유지합니다. 원고를 수정한 상태에서는 저장 또는 폐기 선택 후 이동합니다.

신규 회원가입, 소셜 로그인, 푸시 알림, 앱스토어 배포는 아직 포함하지 않습니다. Bundle ID는 초기값 `app.relaynovel.mobile`이며 스토어 출시 전 실제 계정에 맞춰 확정하세요.

## 검증

```sh
npm run typecheck
npm test
npm run export
```

브라우저에서 모바일 크기로 테스트하려면 `npm run web -- --port 8083` 실행 후 `npx playwright test`를 실행합니다. 로컬 Chrome이 필요합니다. 탐색·필터·읽기와 모의 백엔드를 통한 로그인·모집·임시저장·발행 흐름을 검증합니다.

전송 계층 테스트는 동시 토큰 갱신, 만료 세션 처리, 로그아웃 중 갱신 완료, 집필 차례 충돌, 서버 유효성 오류를 확인합니다. Expo export는 iOS·Android·웹 번들을 생성하며 실제 기기 테스트와는 별개입니다.

```text
app/                  로그인, 탐색, 모집, 초대, 읽기, 집필 화면
src/api/              기존 Bookey API 계약, 요청, 미리보기 데이터
src/state/            인증 세션과 네이티브 토큰 저장
src/components/       별사탕과 공용 UI
src/theme/            디자인 토큰
tests/                인증 및 API 전송 검증
```

참고로 제공된 Claude Artifact는 접근 제한으로 실제 화면을 확인하지 못했으며, 이 디자인은 3D 별사탕 요청을 바탕으로 새로 구성한 첫 버전입니다.
